マーカーでクイズ

教科書やノートの写真やPDFに指でマーカーを引くと、
その場所を隠した4択クイズが自動でできます。

オフラインで動作・データは端末内のみ

写真・マーク・成績はこの端末の中（ブラウザのIndexedDB）だけに保存されます。

使い方

  1. 写真 / PDF：教科書・ノート・プリントを撮る（または写真・PDFを選ぶ）。PDFは取り込むページを選べます。まずは「サンプルで試す」「デモを見る」でも。
  2. マーク：覚えたい語句を指でマーカー（色は自由）。鉛筆で下線や丸囲みもOK。2本指でズーム/移動。「強調」で出題される場所を確認。
  3. 難易度を「やさしい / 中 / 難しい」から選び、「クイズを作る」。
  4. 語句：隠れている語句を入力すると文字の4択に。スキップすれば画像の4択だけで出題。
  5. クイズ：隠された場所（赤シート）に入るものを4つから選ぶ。
  6. 結果：復習して「間違えた問題だけ」「難易度を上げて」再挑戦。

PDFについて

  • PDFの各ページを長辺1600pxの画像に変換して取り込みます。複数ページを選ぶとページごとに履歴に並び、1ページずつクイズにできます。
  • PDFの表示には Mozilla の pdf.js（Apache License 2.0）を使います。初回だけインターネットから部品をダウンロードするため通信が必要です（PDFの内容そのものは外部に送信されません）。
  • 完全オフラインで使うには、このHTMLと同じフォルダーに pdf.min.js と pdf.worker.min.js（pdfjs-dist 3.11.174 の legacy/build）を置いてください。日本語フォントが埋め込まれていないPDFのために cmaps/・standard_fonts/ フォルダーも一緒に置くとより確実です。
  • パスワード付きPDFはパスワードの入力を求めます。
  • スマートフォンでは「ファイル」アプリ（iPhone）や「ファイル」「ドライブ」（Android）からPDFを選べます。

制限時間なし1問20秒1問10秒

ホーム画面に追加して使う

  • iPhone（Safari）：共有ボタン → 「ホーム画面に追加」。
  • Android（Chrome）：メニュー（⋮） → 「ホーム画面に追加」または「アプリをインストール」。
  • このファイルを端末に保存（ファイルアプリ・Google ドライブなど）して開いても動きます。

データについて

  • 写真・マーク・語句・成績はこの端末のブラウザ内（IndexedDB）にだけ保存され、外部には送信されません。
  • 写真・PDFのページは長辺1600pxに縮小したJPEGとして保存します。履歴画面から個別に削除、JSONで書き出し/読み込みができます。
  • ブラウザのサイトデータを消去するとデータも消えます。大切なものは「書き出し」で保存してください。

バックエンドについて

このアプリは1つのHTMLファイルの中で「フロントエンド（画面・描画）」と「バックエンド（保存・領域検出・クイズ生成・採点）」を分けて実装しています。バックエンドは LocalBackend クラスとして端末内で動作し、写真を外部へ送りません。同じAPIを持つ RemoteBackend（サーバー版のひな形）に差し替えればクラウド同期版にも拡張できます。
