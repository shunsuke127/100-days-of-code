# 100 Days of Code Challenge 🚀

This repository contains the projects and tools I build during my `#100DaysOfCode` journey, leveraging AI and modern web technologies.

## Day 1: Kusutto Camera (クスッとカメラ)
A browser-based web application that generates humorous captions for daily photos.

- **Features:** 
  - Fully client-side image processing (FileReader API)
  - Album saving using LocalStorage
  - Native sharing via Web Share API
- **Tech Stack:** HTML, CSS, Vanilla JavaScript
